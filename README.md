# CO₂ PINN v5.2｜地下二氧化碳封存三維模擬

## 專案介紹

本專案以地下二氧化碳（CO₂）地質封存為研究主題，結合物理資訊神經網路（Physics-Informed Neural Network，PINN）與三維視覺化技術，展示地下儲層中 CO₂ 飽和度的模擬分布。

透過互動式網頁，使用者不需要安裝專業模擬軟體，即可直接使用瀏覽器觀察三維模型，並進行旋轉、縮放與平移。

## 技術原理

### 1. 地下 CO₂ 地質封存

地下 CO₂ 地質封存是將二氧化碳注入適合的地下地質構造，以研究其在儲層中的分布、流動及長期封存行為。

### 2. 物理資訊神經網路（PINN）

PINN 是結合神經網路與物理方程式的機器學習方法。

本研究以 PINN 建立地下 CO₂ 封存模擬模型，利用物理約束輔助學習儲層中的壓力與 CO₂ 飽和度分布。

### 3. 三維視覺化

本網站使用 Three.js 將模型輸出資料轉換為互動式三維網格。

不同顏色代表不同的 CO₂ 飽和度數值，方便觀察模擬結果的空間變化。

目前展示的是第 100 天的模擬結果，並非即時運算或完整時間序列動畫。

## 網頁操作方式

- 滑鼠左鍵拖曳：旋轉三維模型
- 滑鼠滾輪：放大或縮小
- 滑鼠右鍵拖曳：平移視角

## 專案目標

本專案希望透過 PINN 與網頁三維視覺化技術，讓地下 CO₂ 地質封存的模擬結果更容易理解與展示，作為工程模擬、課堂學習及後續研究的基礎。

**備註：本網站展示的是數值模型模擬結果，不代表實際地質場址的量測資料或經驗證的封存預測。**
